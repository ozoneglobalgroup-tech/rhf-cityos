# مسیر تکمیل سیستم‌عامل جامع معاونت خدمات شهری

**این بسته پایه عملیاتی است، نه پایان پروژه.**

۱. انتقال هسته فعلی RUVOS و یکپارچه‌سازی SSO / Keycloak؛ جلوگیری از دو سرویس مستقل در مقصد.
۲. مدل Organization Scope (سازمان، منطقه و ناحیه برای هر کاربر)، اختیارات مؤثر در تاریخ و تفویض اختیارات.
۳. موتور Workflow قابل پیکربندی، فرم‌ساز، مدارک و پذیرش کار با MinIO.
۴. تکمیل کامل ماژول‌های تخصصی ۲۳ حوزه: پسماند، نظافت، فضای سبز، زیباسازی، آتش‌نشانی، مشاغل، میادین، آرامستان‌ها، انضباط شهری، ناوگان، قرارداد و پیمانکار، GIS، ۱۳۷ و غیره.
۵. اتصال به HRP، Finance، Fleet، GIS، IoT و سامانه‌های موجود از طریق Connectors نه داده ساختگی.
۶. موتور ارزش پیشرفته: Target/Baseline، روش انتساب، اثبات مالی، عدم دوباره‌شماری، پیامدهای اجتماعی/محیطی، تأیید چندسطحی.
۷. معماری AI Agents با کنترل انسانی، عدم اجرای خودکار اقدامات پرخطر و دفتر وقایع.
۸. عملیاتی‌سازی: CI/CD، Git، کنترل کیفیت API، تست JWT/RLS/E2E، Monitoring، Backup و Restore، آزمون بار، مدیریت تغییر و انتشار امن.

**اصل ثابت:** ماژول‌های جدید داخل اپلیکیشن React و API واقعی توسعه یابند؛ HTML مستقل تولید نشود.
